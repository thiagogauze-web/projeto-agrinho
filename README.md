## 📝 Sobre o Projeto

Este website foi desenvolvido especialmente como parte da participação no **Concurso Agrinho**. O objetivo principal da plataforma é disseminar conhecimento sobre práticas agrícolas sustentáveis, uso consciente dos recursos naturais e a importância da tecnologia no desenvolvimento do ecossistema rural.

Através de uma interface simples, limpa e responsiva, o site busca conscientizar estudantes, produtores rurais e a comunidade em geral sobre como pequenas ações locais geram grandes impactos globais no meio ambiente.

---

## 🚀 Funcionalidades Principais

* **Design Temático e Responsivo:** Cores e elementos visuais que remetem ao campo e à natureza, adaptando-se perfeitamente a computadores, tablets e celulares.
* **Seções Informativas:** Explicações claras sobre os pilares do programa Agrinho e da sustentabilidade rural.
* **Painel de Dicas Interativas (Cards):** Cards modernos destacando a economia de água, o uso de energias limpas e a preservação do solo.
* **Formulário de Sugestões:** Canal interativo onde os visitantes podem enviar suas próprias ideias sustentáveis, com validação de dados em tempo real via JavaScript.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras, sem a necessidade de frameworks complexos, garantindo leveza e rapidez no carregamento:

* **HTML5:** Estruturação semântica de todo o conteúdo da página.
* **CSS3:** Estilização visual, uso de CSS Grid, Flexbox e criação de layout responsivo (Media Queries).
* **JavaScript (ES6):** Manipulação do DOM para controle do formulário e exibição dinâmica de mensagens de sucesso.
